# AutoKey — 类按键精灵的按键编排工具（AutoHotkey v2）

在 Windows 上自动按键、编排按键序列，并可指定目标应用程序。  
**全部在图形界面里配置**，无需手改配置文件。

本仓库在 macOS 上只负责编写脚本；**最终产物是 Windows 绿色版 exe**（约 1–2 MB）。

## 功能

- **连发模式**（默认）：可动态添加多个键位，按列表顺序轮流连发；每个键可单独设间隔
- **按键序列**：用“添加按键 / 添加等待 / 添加点击”快捷编排，多步按顺序执行
- **可视化坐标拾取**：十字准星指向目标位置，单击即可记录并自动绑定目标窗口
- **多套配置**：左侧新建、复制、切换、删除多套方案；选中窗口后在名称后以 `[进程 #序号]` 标识，不改动也不写入窗口标题
- 按进程名（`exe`）定位目标；多开时用「选择目标窗口…」锁定具体实例
- **同一客户端多开**：可锁定具体窗口句柄，或指定「第几个窗口」，多套配置各控一个互不抢占
- 开始 / 停止 / 暂停热键（支持界面内「捕捉」）
- 循环次数与间隔可配
- `Send`（前台）或 `ControlSend`（尽量后台）
- 配置自动保存到 `data\`（同级可写时）；若目录只读/无权限，会自动改存到 `%AppData%\AutoKey\`
- 请先把 Actions 产物**解压到普通文件夹**再运行，不要在压缩包里直接双击，也不要放到 `Program Files`
- 可导入旧版 `configs\*.ini`（兼容）
- 打包为绿色 `dist\` 目录，拷走就能跑

## 界面怎么用

1. 左侧选择、「新建」或「复制」一套配置
2. 点上方 Tab 切换编辑区（一次只显示一种）：
   - **连发模式**：填按键（或「捕捉」直接加入）+ 间隔，可继续加入更多键位
   - **按键序列**：直接选择「添加按键」「添加等待」或「添加点击」，无需先选步骤类型；双击已有步骤可快速编辑
3. 按需设循环、热键、目标窗口；点击「选择目标窗口…」后可最小化 AutoKey 并直接点选，也可从实时列表选择
4. 点 **保存并应用**，再点 **开始**。多套配置可同时运行；用 **全部停止** 一键停掉
5. 默认 **ControlSend + 不激活**，后台推送按键；**点击步骤始终是真实鼠标点击**，多套配置同时跑时会自动排队轮流点各自窗口（不互抢乱点，但会短暂切换前台）

常用按键写法：`a`、`{Enter}`、`{Space}`、`{Tab}`、`{Esc}`、`{F1}`、`^c`（Ctrl+C）、`!{F4}`（Alt+F4）。

### 可视化选择点击位置

1. 在「按键序列」中点击 **添加点击**
2. 选择 **左键/右键**、**单击 / 双击 / 自定义次数**，以及 **连点间隔**（默认 80ms，游戏认不出可调到 100–150），再点 **拾取坐标…**，AutoKey 会暂时隐藏
3. 将十字准星移到目标程序的内容区域，左键单击确认；按 `Esc` 可取消
4. AutoKey 会记录窗口客户区相对坐标，并自动锁定鼠标下的目标窗口

坐标相对于目标窗口内容区域保存，因此窗口移动后仍会点击同一位置。请不要拾取标题栏或窗口边框；目标窗口关闭、重开后如句柄变化，可重新拾取，或依靠自动记录的「窗口 #」继续定位。旧配置未指定按键时默认左键。

点击用系统真实鼠标，但内部有**全局排队**：多开游戏可同时启动多套带点击的配置，点击会轮流执行到各自锁定的窗口，不会两套一起乱点。代价是点击时会短暂把对应窗口置前；纯按键步骤仍可后台并行、不受排队影响。

### 同一个客户端多开怎么配

只填 `exe` 是分不出多开的哪一个的。点击 **选择目标窗口…** 后提供两种选法：

- **直接点选**：AutoKey 自动最小化，点击目标游戏窗口后立即恢复，适合快速选择某个多开实例。
- **实时列表**：仅在选择窗口对话框打开时监听可见窗口变化；关闭后立即停止，不后台常驻。

选中后会同时锁定当前窗口句柄并记录「窗口 #」。句柄在本次运行中最准确；客户端重启后可按记录的序号重新定位，必要时再次选择。

每套配置配一个窗口，多套一起开始即可。运行中的配置会占用自己的窗口，其它配置在自动模式下会自动避开。

## 目录结构

```
autokey/
├── src/
│   ├── AutoKey.ahk          # 主程序（可视化配置 GUI）
│   └── lib/
│       ├── Config.ahk       # 多套配置 + 自动持久化
│       ├── Target.ahk       # 目标窗口定位
│       └── Sequencer.ahk    # 序列执行器
├── configs/                 # 旧版 ini 示例（可「导入旧 ini」）
├── data/                    # 运行时自动生成，保存你的 UI 配置
├── build/build.bat          # Windows 一键编译
├── tools/ahk/               # 自动下载的 AHK 便携版（gitignore）
├── dist/                    # 编译输出（gitignore）
└── .github/workflows/       # 在 GitHub 上自动打 Windows 包
```

## 在 Windows 上使用

### 方式 A：直接跑脚本（开发调试）

1. 安装 [AutoHotkey v2](https://www.autohotkey.com/v2/)
2. 双击 `src\AutoKey.ahk`
3. 在界面里配置 → 保存并应用 → 开目标程序 → 开始

### 方式 B：打成绿色 exe（推荐分发）

在 **Windows** 上双击：

```bat
build\build.bat
```

首次运行会自动把 AutoHotkey v2 和 Ahk2Exe 编译器的**便携版**下载解压到 `tools\ahk\`。  
完成后得到 `dist\AutoKey.exe`，拷到任意 Windows 机器即可。

编译前会先做一次语法检查（`AutoHotkey64.exe /validate`），脚本有错会直接报出文件和行号。

#### 双击后没有生成 dist 怎么办

先看窗口里 `---------- Ahk2Exe 输出 ----------` 之间的内容，那是真实原因；完整日志在 `dist\build.log`。其它排查：

1. **必须下载整个仓库**，不能只单独下载 `build.bat`
2. **确认行尾是 CRLF**（仓库已用 `.gitattributes` 处理；若仍有问题见下方 PowerShell 修复）
3. **不要在压缩包里直接双击**，先解压到可写目录

```powershell
$p = "build\build.bat"
(Get-Content -Raw $p) -replace "`r?`n", "`r`n" | Set-Content -NoNewline $p
```

#### 提示「找不到 Ahk2Exe.exe」

到 [Ahk2Exe releases](https://github.com/AutoHotkey/Ahk2Exe/releases) 下载 zip，解压到 `tools\ahk\Compiler\`，确保存在 `Ahk2Exe.exe` 后重跑 `build.bat`。

### 方式 C：在 Mac 上开发，用 GitHub Actions 打包

1. 把仓库推到 GitHub  
2. Actions → **Build Windows EXE** → 下载 `AutoKey-windows`  
3. **解压到桌面或文档等可写目录**，再运行 `AutoKey.exe`（不要在 zip 里直接打开）
4. 若仍提示无法保存配置，配置会自动写到 `%AppData%\AutoKey\`；也可手动把整个文件夹拷到非系统目录

## 注意

- 仅支持 **Windows**（Win7+，建议 Win10/11）
- 部分游戏使用反作弊 / DirectInput，普通 `Send` 可能无效
- `ControlSend` 后台发送对很多程序无效，默认用 `Send` 更稳
- 请遵守目标软件/游戏的使用条款
- 运行中若出现报错，详情会写到配置目录下的 `error.log`（与 `macros.ini` 同一目录），反馈问题时带上这段内容即可定位

## 快速验证

1. 打开 Windows 记事本  
2. 连发模式：加入 `h`，间隔 `80`；或再加入更多键位轮流连发  
3. 通过「选择目标窗口…」最小化 AutoKey 后点击记事本
4. 保存并应用 → F6 开始 / F7 停止
5. 按键序列：依次添加一个按键、一个等待和一个点击步骤
6. 拾取记事本内容区域中的位置，确认界面显示客户区坐标且目标窗口已自动锁定
7. 移动记事本窗口后保存并开始，确认点击仍命中窗口内同一位置
8. 再次拾取时按 `Esc`，确认取消后原点击步骤与目标窗口不变
